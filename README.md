# Saudi AI Research Engine

This repository is the controlled integration target for a Saudi Exchange research engine derived from the user-owned `ku-bo` and `AI-Mincy` repositories.

The intended result is a KU-BO-based runtime that reaches tested behavioral parity with useful AI-Mincy capabilities, while replacing Kuwait-specific active-market assumptions with a market-adapter architecture and a Saudi-first implementation.
